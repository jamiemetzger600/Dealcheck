## 🐛 If Issues Come Up

### Common Issues & Solutions

**Issue**: "Can't load deals"
- **Solution**: Check browser console (F12), might be CORS issue

**Issue**: "Data disappeared"
- **Solution**: Uses localStorage - clearing browser data clears deals

**Issue**: "Slow on mobile"
- **Solution**: Might be too many deals - try filtering first

**Issue**: "Can't find a feature"
- **Solution**: Good feedback! Note what they were looking for

### Reporting Issues
1. Note the URL where issue occurred
2. Describe what happened vs. what was expected
3. Include browser and device info
4. Screenshots are helpful!
