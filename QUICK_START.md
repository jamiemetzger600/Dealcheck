# 🚀 Quick Start Guide - v2.1.8

## Installation
1. Open Chrome → Extensions → Load Unpacked
2. Select `Gemini Deal Analyzer` folder
3. Extension loads with v2.1.8

## First Use (5-Minute Walkthrough)

### 1. Open Dashboard
- Click extension icon on any page
- Dashboard opens in full screen

### 2. Fetch Deals (30 seconds)
- Click **"🔄 Fetch Deals"** button (top)
- Wait for aggregation to complete
- See deals populate in table

### 3. Configure Buy Box (2 minutes)
- Click **"⚙️ Configure Buy Box"** button
- Set your criteria:
  - Price range: $2M - $5M
  - EBITDA: $500K+
  - States: TX, FL, GA
  - Industries: Check your targets
- Click **"💾 Save Buy Box"**
- See 🎯 badges on matching deals

### 4. Save a Deal (10 seconds)
- Find interesting deal in table
- Click **"💾"** button on that row
- Toast confirms save
- Badge count increases

### 5. Manage Your Pipeline (1 minute)
- Click **"My Deals"** tab
- See your saved deals
- Click deal name to view details
- Change status with dropdown
- Add notes (auto-saves)

### 6. Add Off-Market Deal (1 minute)
- Click **"➕ Add Deal"** button
- Fill in business information
- Click **"💾 Save Deal"**
- Appears in both tabs

## Key Features

| Feature | Button/Action | Result |
|---------|---------------|--------|
| **Fetch Deals** | 🔄 Fetch Deals | Aggregates from all sources |
| **Filter Deals** | ⚙️ Configure Buy Box | Sets investment criteria |
| **Save Deal** | 💾 (in table) | Adds to My Deals |
| **View Details** | Click deal name | Opens full modal |
| **Change Status** | Dropdown in modal | Hot/Warm/Cold/Pass |
| **Add Notes** | Type in modal | Auto-saves after 1s |
| **Export** | 📤 Export | Downloads CSV |
| **Delete** | 🗑️ Delete | Removes deal |
| **Manual Entry** | ➕ Add Deal | Enter off-market |
| **Manage Sources** | 📥 Manage Sources | Add/remove sources |

## Keyboard Tips

## Troubleshooting

**Buttons don't work?**
- Reload extension
- Check console for errors

**No deals showing?**
- Click "Fetch Deals"
- Wait 5-10 seconds
- Check "Manage Sources"

**Modal won't open?**
- Check console
- Refresh page

**CSV won't download?**
- Allow downloads from extension
- Check Downloads folder
