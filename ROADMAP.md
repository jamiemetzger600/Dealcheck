# Product Roadmap

## Planned Features

### 🎯 High Priority

#### Deal Comparison
- Save multiple deals for side-by-side comparison
- Compare key metrics across saved deals:
  - Max Allowable Price vs Asking Price
  - DSCR and debt service
  - Free cash flow and owner take-home
  - Financing structures
- Visual comparison table or cards
- Ability to name/tag deals for easy reference
- Export comparison as PDF or spreadsheet

**Benefits:**
- Evaluate multiple opportunities simultaneously
- Make data-driven decisions on which deal to pursue
- Track deal pipeline

#### ROI Calculator ✅ (Completed in v1.3.0)
- Cash-on-Cash Return calculation ✅
- Payback period (time to recover initial investment) ✅
- Total ROI over time periods (3yr, 5yr, 10yr)
- IRR (Internal Rate of Return)
- Equity multiple
- Break-even analysis
- Return metrics visualization (charts/graphs)

**Benefits:**
- Understand true return on investment ✅
- Compare deals on ROI basis, not just cash flow
- Set investment goals and benchmarks

### 💡 Future Enhancements

#### Comparable Deals Analysis (v2.0)
**Comp Database:**
- Manual entry of comparable deals
- Track: Sale price, EBITDA/SDE, Revenue, Location, Industry, Date
- Local storage for comp library
- Import/Export comp data (CSV)

**Comp Metrics:**
- Price/EBITDA multiple comparison
- Revenue multiple analysis
- Cap Rate comparison (for real estate businesses)
- DSCR comparison across comps
- Geographic market adjustments

**Comp Analytics:**
- Visual comp table (sortable/filterable)
- Average/median/range calculations
- Deal quality score vs market
- Percentile ranking
- Color-coded indicators (good/bad deal)

**Smart Filters:**
- By industry/sector
- By location/market
- By deal size range
- By recency (6mo, 1yr, 2yr)
- By EBITDA margin similarity

**Benefits:**
- Market-based valuation validation
- Identify undervalued opportunities
- Support negotiation with data
- Build institutional knowledge

#### Working Capital Analysis
- Calculate working capital adjustments
- Inventory/AR/AP considerations
- Normalized working capital requirements
- Impact on purchase price and cash needed

#### Break-even & Scenario Analysis
- Minimum EBITDA needed to cover debt service
- "What if" scenario modeling:
  - EBITDA drops 10%, 20%, 30%
  - Interest rate changes
  - Revenue decline scenarios
- Stress testing
- Downside protection analysis

#### Exit Strategy Calculator
- Project business value in 3/5/7 years
- Calculate ROI with various exit multiples
- Include equity paydown in exit value
- Growth rate assumptions
- Terminal value scenarios

#### Deal Notes & Due Diligence Tracker
- Built-in due diligence checklist
- Pros/cons list for each deal
- Red flags tracker
- Follow-up items and tasks
- Deal timeline/milestones
- Document attachments/links

#### Multi-Deal Portfolio View
- Dashboard showing all saved deals
- Portfolio analytics
- Decision matrix
- Deal pipeline stages
- Win/loss tracking

#### Sensitivity Analysis
- Show how deal metrics change with:
  - Different interest rates (+/- 2%)
  - EBITDA variations (+/- 10%, 20%)
  - Different DSCR targets
  - Various down payment percentages
- Visual charts showing sensitivity ranges
- Risk assessment based on variability

#### Market Intelligence
- Industry-specific multiple benchmarks (SaaS, Retail, Manufacturing, etc.)
- Trending multiples over time
- Risk factors by industry
- Seasonality considerations

#### Integration Features
- Import data from BizBuySell, BizQuest APIs
- Export to Excel/Google Sheets
- Sync with CRM systems
- Calendar integration for deal milestones
- Email integration for deal updates

**Premium Version ($9.99-19.99/month or $99-149/year):**
