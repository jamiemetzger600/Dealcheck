# Share Deal Analysis Feature - v1.9.20

## Overview
The Share Deal Analysis feature allows users to quickly share comprehensive deal information including financial details, broker contacts, progress tracking, and scenario analyses via multiple channels.

---

## Features

### Share Channels

1. **📧 Email**
   - Opens default email client
   - Complete formatted deal analysis in body
   - Subject line: "Deal Analysis: [Deal Name]"
   - Ready to send to partners, investors, or team members

2. **💬 SMS/Text**
   - Opens messages app
   - Optimized shorter format for SMS character limits
   - Includes: Deal name, asking price, EBITDA, quality score, and link
   - Perfect for quick deal sharing

3. **📋 Copy Link**
   - Copies full deal analysis to clipboard
   - Can be pasted into any application
   - Includes all scenarios, financials, and broker info
   - Works on all devices

4. **📲 Share (AirDrop)**
   - Uses native system share dialog
   - Supports AirDrop on macOS/iOS
   - Share to any installed app
   - WhatsApp, Slack, Notes, etc.

---

## What Gets Shared

### Complete Deal Package Includes:

#### 1. Overview
- Deal name
- Status (Hot/Warm/Cold/Pass)
- Saved date
- Quality score
- Direct link to listing

#### 2. Financial Highlights
- Asking Price
- EBITDA
- Max Price
- COC Return
- Total Debt
- FCF Annual
- Owner Take-Home
- Payback Period

#### 3. Broker Contact Information
- Broker/Agent name
- Company name
- Phone number
- Email address

#### 4. Deal Progress (Recent 5 Updates)
- Status updates with dates
- Most recent progress shown first

#### 5. Scenario Analyses (If Calculated)
For each scenario (up to 3):
- Purchase price & EBITDA
- Deal structure breakdown (SBA%, Equity%, Seller Note%)
- Dollar amounts for each component
- Financing terms (rates and durations)
- Key metrics:
  - Total Debt Service
  - Annual Cash Flow
  - COC Return
  - DSCR
  - Payback Period

#### 6. Recommendation
- Identifies best scenario based on weighted analysis
- Considers COC return, DSCR, and cash flow
- Clear "Recommended: Scenario X" callout

#### 7. Notes
- User's custom notes about the deal

## How to Use

### Accessing Share Feature

1. Open **Deals Dashboard** (📊 icon in extension)
2. Click on any **deal name** to open modal
3. Click **"📤 Share"** button in footer
4. Share modal opens with preview

### Sharing Process

```
1. Click "📤 Share" button
   ↓
2. Preview shows complete analysis
   ↓
3. Choose share method:
   - Email → Opens email with full text
   - SMS → Opens messages with summary
   - Copy Link → Copies to clipboard
   - Share → System share dialog (AirDrop)
   ↓
4. Complete sharing through chosen method
   ↓
5. Success notification confirms action
```

## Technical Details

### Share Text Generation

The `generateShareText()` function:
- Assembles data from current deal object
- Formats financial numbers with currency
- Includes calculated scenarios if available
- Identifies recommended scenario using weighted scoring
- Adds timestamp and version footer

### Scenario Recommendation Logic

```javascript
Weighted Score = (COC Return × 2) + (DSCR × 10 × 1.5) + (Annual Cash Flow / 10,000)

- COC Return weighted 2x (most important for investor returns)
- DSCR weighted 1.5x (important for loan approval)
- Cash Flow weighted 1x (base importance)

Highest scoring scenario = Recommended
```

### Character Limits

- **Email:** No practical limit (handles full analysis)
- **SMS:** Shortened to ~160 characters for compatibility
- **Clipboard:** No limit
- **Native Share:** Platform dependent (usually generous)

## Browser Compatibility

### Web Share API (AirDrop/Native Share)

✅ **Supported:**
- Safari on iOS/iPadOS (AirDrop available)
- Safari on macOS 12.1+ (AirDrop available)
- Chrome on Android
- Edge on Windows

❌ **Not Supported:**
- Chrome on desktop (automatic fallback to copy)
- Firefox on desktop (automatic fallback to copy)

**Fallback:** If Web Share API unavailable, automatically copies to clipboard with notification.

### Clipboard API

✅ **All Modern Browsers:**
- Chrome 63+
- Firefox 53+
- Safari 13.1+
- Edge 79+

**Fallback:** Uses `document.execCommand('copy')` for older browsers.

## Troubleshooting

### "Email client not opening"

**Issue:** Default email app not configured  
**Solution:** 
1. Try "Copy Link" instead
2. Paste into web email (Gmail, Outlook.com)
3. Set default email app in system settings

### "SMS not working"

**Issue:** SMS app not configured or device doesn't support SMS  
**Solution:**
1. Use "Share" button → WhatsApp or other messaging app
2. Use "Copy Link" and paste into messenger manually

### "AirDrop not appearing"

**Issue:** Web Share API not available or AirDrop disabled  
**Solution:**
1. Ensure Bluetooth and Wi-Fi enabled (required for AirDrop)
2. Check AirDrop settings → "Everyone" or "Contacts Only"
3. Try "Copy Link" and share via Messages app instead

### "Share button missing"

**Issue:** Old browser version or cached page  
**Solution:**
1. Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
2. Clear cache and reload
3. Update browser to latest version

### "Copied text looks garbled"

**Issue:** Special characters or formatting issues  
**Solution:**
1. Paste into plain text editor first (TextEdit, Notepad)
2. Then copy from plain text to destination
3. Format may vary by destination app
