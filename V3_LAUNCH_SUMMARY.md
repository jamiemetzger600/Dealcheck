## 🔄 How Updates Work

### Automatic Deployment

Every time you push to GitHub:
```bash
git push origin feature/web-deployment
```

Vercel automatically:
1. Detects the push
2. Builds the site
3. Deploys to production
4. Updates https://jackpops.vercel.app

**Time**: ~30 seconds from push to live!

### Manual Deployment

Or deploy manually:
```bash
cd web
vercel --prod
```
