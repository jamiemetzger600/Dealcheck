Frontend Hosting
Web App (React + Vite PWA)
⚠️
Important — Vercel Commercial Use: Your project already has Vercel configured (web/.vercel/). However, Vercel's Hobby (free) plan explicitly prohibits commercial use in their Terms of Service. Since Vettr has paid tiers via Stripe, you would technically need to upgrade to Vercel Pro ($20/mo) once you start earning revenue. Cloudflare Pages is the stronger free-forever alternative.

☁️ Cloudflare Pages

RECOMMENDED
$0
Free — Forever (Commercial OK)
  • ✔ Unlimited bandwidth — no caps, ever
  • ✔ 500 builds/month (plenty for solo)
  • ✔ Commercial use explicitly allowed
  • ✔ Git-connected CI/CD (auto-deploy on push)
  • ✔ Global CDN — among the fastest in the world
  • ✔ Automatic HTTPS / SSL
  • ✔ Custom domains included
  • ✔ React + Vite builds supported out-of-the-box
Paid tier: ~$20/mo (Workers Paid) — only needed at very high scale

▲ Vercel

ALREADY CONFIGURED
$0 → $20
Hobby Free / Pro $20/seat/mo
  • ⚠ Free tier = non-commercial use only (violates ToS with paid product)
  • ✔ 100 GB bandwidth/month on free
  • ✔ 1 TB bandwidth/month on Pro
  • ✔ Already integrated with your project
  • ✔ Excellent DX — instant previews per PR
  • ✔ React + Vite first-class support
  • ✗ Free tier suspended if limits exceeded
Best choice if you're ready to pay $20/mo — great developer experience

🟩 Netlify

ALTERNATIVE
$0 → $19
Free / Pro $19/seat/mo
  • ✔ 100 GB bandwidth/month free
  • ✔ 300 build minutes/month
  • ✗ Suspends ALL projects if any one hits limit
  • ⚠ Commercial use technically allowed, but unclear for revenue-generating apps
  • ✔ Good DX, branch deploy previews
  • ✗ No team seats on free tier
Solid option but the "all sites paused" limit behavior is risky for production
Backend Hosting
Node.js / Express API Server
⚠️
Cold starts matter for your app. Your backend handles Stripe webhooks, JWT auth, and cron jobs — none of these tolerate a 30-second cold start. Avoid any platform that "spins down" free tier services (like Render's free tier). Prioritize always-on services.

🟣 Koyeb

RECOMMENDED FREE
$0
Starter Free — Always On, Commercial OK
  • ✔ Always-on — zero cold starts (restarts only if unresponsive)
  • ✔ 1 vCPU, 512 MB RAM — sufficient for Express
  • ✔ 1 GB bandwidth/month
  • ✔ Includes a free PostgreSQL database
  • ✔ No credit card required
  • ✔ Commercial use allowed
  • ✔ Git-connected auto-deploys
  • ⚠ Limited to 1 free service + 1 DB
Best free starting point — truly persistent, no surprises, handles your full stack

🚂 Railway

$5/MO HOBBY
$5/mo
Hobby Plan (includes $5 credit) — No true free tier
  • ✔ Always-on, no cold starts
  • ✔ One-click PostgreSQL add-on
  • ✔ Usage-based — pay only for what you use
  • ✔ Great DX, easy to scale
  • ✗ No permanent free tier (30-day trial only)
  • ⚠ PostgreSQL can cost ~$18/mo standalone if heavy usage
  • ⚠ Light usage typically stays well under $1/mo for DB
Best "almost free" option — great scaling path, well-suited for your stack

🟡 Render

AVOID FREE TIER
$0 → $7/mo
Free (unusable) / Starter $7/mo
  • ✗ Free tier spins down after 15 min idle
  • ✗ Cold start: 30 seconds to 2 minutes — breaks Stripe webhooks
  • ⚠ PostgreSQL free for 90 days only, then paid
  • ✔ Starter at $7/mo is always-on with 512 MB RAM
  • ✔ Good documentation, easy Node.js deploy
Avoid the free tier. The $7/mo Starter plan is a reasonable paid option

🪁 Fly.io

NO FREE TIER
~$2/mo
Usage-based — free tier removed in 2024
  • ✗ Free tier removed for new users (2024)
  • ⚠ 2-hour trial only for new signups
  • ✔ Very cheap — ~$1.94/mo for shared 256 MB VM
  • ✔ Global edge deployment
  • ✗ Managed PostgreSQL starts at $38/mo
  • ⚠ More ops complexity than Railway/Render
Very cheap compute but no free tier and expensive managed Postgres
Database
PostgreSQL — Standalone Options

If you use Koyeb free tier, its included PostgreSQL may be enough to start. These options are relevant if you need a separate or more scalable DB host.

🌿 Neon (Serverless Postgres)

BEST FREE DB
$0
Free Plan — Never Pauses (active region)
  • ✔ 0.5 GB storage free (enough for early users)
  • ✔ 100 CU-hours compute/month (doubled in 2025)
  • ✔ 5 GB egress/month
  • ✔ Up to 20 free projects
  • ✔ Full PostgreSQL — drop-in compatible with pg npm package
  • ✔ Scales to zero (cost-efficient)
  • ⚠ Serverless — connection pooling needed for Express (use @neondatabase/serverless or pgBouncer)
Pro plan: $19/mo — scales very gracefully from free to production

⚡ Supabase

PAUSES AFTER 7 DAYS
$0
Free / Pro $25/mo
  • ✔ 500 MB storage, 2 GB egress
  • ✔ 50,000 monthly active users (Auth included)
  • ✗ Project pauses after 7 days inactivity
  • ⚠ Resuming requires manual action or Pro upgrade
  • ✔ Full PostgreSQL + Auth + Storage + Realtime
  • ✔ Great if you replace your custom auth with Supabase Auth
Better suited as a BaaS replacement — great if you adopt its auth/storage features

🚂 Railway PostgreSQL

USAGE-BASED
<$1/mo
Light usage — requires Railway account ($5/mo base)
  • ✔ One-click add-on inside Railway
  • ✔ Very cheap for light workloads (<$1/mo)
  • ✔ Private networking — DB and app in same environment
  • ⚠ Can reach ~$18/mo for heavy traffic
  • ✔ Automatic backups
Natural pairing with Railway backend — bundled usage billing is convenient

Bottom line: Start with Cloudflare Pages (frontend) + Koyeb Free (backend + PostgreSQL) — that's a fully functional, always-on, zero-cost production stack with no ToS issues. Migrate to Railway ($5/mo) as your first user-driven upgrade, and graduate to Vercel Pro + Neon Pro once your MRR justifies it.
